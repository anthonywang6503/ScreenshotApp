## 範圍與自行決定的假設（使用者可覆寫）

1. **放大鏡**：只在選取覆蓋層中、按住 Ctrl 時顯示（放開即隱藏）；以快照像素為來源（不經暗化）、整數實體像素倍率、游標像素置中並加框；附「座標（顯示器實體像素）與 `#RRGGBB`」。觸發截圖的快捷鍵本身含 Ctrl，進入覆蓋層時仍按著的 Ctrl 不顯示放大鏡，必須重新按下。方向鍵逐像素移動游標不在範圍內（可列為後續）。
2. **取色器**：兩個入口。(a) 選取覆蓋層按 `C`：把游標像素的 `#RRGGBB` 文字複製到剪貼簿、結束這次截圖（不建立文件）並以系統匣通知顯示色碼；(b) 編輯器「取色」工具：點擊讀取原圖像素，套用為目前顏色（與顏色清單相同的套用路徑），之後回到原本的工具。
3. **馬賽克、模糊**：兩種新的「效果標註」，以矩形範圍描述，可選取、移動、調整大小、再製、刪除、復原。效果只取樣**原圖**像素（不含其下的標註），以不透明點陣圖覆蓋，因此其下的標註也被遮住。強度可調（馬賽克區塊大小、模糊半徑），不寫入設定檔。模糊不保證無法還原；需要降低可辨識度時優先馬賽克並檢查匯出結果，兩者皆不保證保密。原圖仍在文件與已啟用的歷史中；以演算法期望值與不透明覆蓋驗收，不要求每個像素都與原值不同。
4. **尺規**：(a) 編輯器的線段型「尺寸標註」，兩端有垂直於線段的界線，中央標示長度，會輸出到圖片；(b) 選取覆蓋層按 `R` 切換「量測模式」：拖曳畫出量測線並顯示長度、Δx、Δy 與外接範圍寬高，不建立文件，再按 `R` 回到區域選取，`Esc` 結束截圖；放大鏡在兩種模式都可用。Phase 8 已定義共用長度為兩端像素中心距離，寬高包含端點（abs 差值＋1），長度顯示至小數一位；Phase 11 的 ADR 沿用並以測試釘住。
5. **截圖歷史**（Q1）：預設開啟。每次完成的截圖（含長截圖）寫入 `%LocalAppData%\ScreenshotApp\history\` 的一個條目（原圖 PNG、縮圖、內部 JSON：標註、裁切、時間、結構版本），可重新開啟繼續編輯（復原紀錄不保留）；開啟的既有圖片不記錄。截圖完成時寫入原圖，文件被取代、關閉、結束與每次成功複製或另存時更新標註。設定可關閉歷史與調整保留筆數（預設 50，1～500），歷史視窗與設定都能清除全部。第一次建立歷史資料夾時以系統匣通知告知已開啟與關閉方式。寫入失敗不阻擋截圖；關閉後停止新增及更新，不補存關閉期間的內容；已刪除或淘汰的條目不被待寫入工作重建。內部 JSON 不是對外的 `.shot` 專案格式（規格第 11 節維持不做）。
6. **長截圖**（Q2）：入口為系統匣「長截圖」與設定中的「長截圖快捷鍵」（預設未設定，避免與其他程式衝突）；沿用選取覆蓋層選範圍（單一顯示器）；選好後使用者可直接以滾輪捲動底下的程式，控制面板另有「自動捲動」；只支援向下捲動的垂直拼接；高度上限 32,768px、總像素上限 100,000,000，只附加上限內完整新列，達到時自動停止並提示；完成後開啟編輯器並依設定加入歷史。不使用低階鍵盤或滑鼠 Hook（規格第 2 節）；自動捲動期間偵測到使用者輸入即停止自動捲動。
7. 一般截圖流程不變：放開滑鼠即開啟編輯器（FR-11）。
8. 新的使用者可見文字全部放在 `Strings.resx`；新的 Win32 宣告集中於 `NativeMethods`；座標換算只經過 `CoordinateMapper`；新標註只透過既有命令進入 `UndoRedoStack`；檔案寫入沿用「同資料夾暫存檔後取代」與背景編碼。

## Decisions Made
| Decision | Rationale |
|----------|-----------|
| 新 Phase 從 08 接續編號，每個功能一個 Phase | 沿用 `phase-<NN>` 分支與 commit 慣例；每個 Phase 可獨立驗收與暫停 |
| 先修訂規格（Phase 8）再實作 | AGENTS.md：需求變更先修改規格；七項功能都列在規格第 11 節「不實作」 |
| Phase 順序：放大鏡 → 效果 → 尺規 → 歷史 → 長截圖 → 發佈 | 低風險、獨立的先做；歷史需涵蓋全部標註種類；長截圖風險最高且要加入歷史，放在最後 |
| 效果標註只取樣原圖、以不透明點陣圖覆蓋 | 取樣不受下層標註影響；覆蓋仍遵守層序；成品不附帶原圖，均勻區塊可能維持原色 |
| Phase 8 補足數值與邊界 | 尺規使用像素中心距離；歷史保留 1～500 筆；長截圖上限 32,768px／100,000,000 像素；提供後續實作可驗證的界線 |
| 長截圖預設快捷鍵未設定 | 避免新增的預設組合與使用者其他程式衝突而在啟動時跳出錯誤通知 |
| 截圖歷史預設開啟、存於磁碟（使用者 Q1） | 使用者明確選擇；以通知、關閉、清除與保留上限降低隱私衝擊 |
| 長截圖提供手動與自動捲動（使用者 Q2） | 使用者明確選擇；手動為預設，自動捲動先實測注入方式 |
| 尺規做編輯器尺寸標註＋覆蓋層量測（使用者 Q3），覆蓋層以 `R` 切換 | 使用者選 1 與 3；Ctrl（放大鏡）與 `C`（取色）已占用，`R` 對應 Ruler |
