# 已知限制

本文件列出 ScreenshotApp v1.1.0 與目前開發版已知的功能限制與不支援的情境；放大鏡、取色、馬賽克、模糊與尺規為尚未發佈的開發版功能。各項功能的實機驗證範圍與尚未驗證的環境見 [ACCEPTANCE.md](ACCEPTANCE.md)。

## 發佈與執行環境

- **只提供 Windows x64 版本**：正式驗收平台為 Windows 11 x64；Windows 10 x64 盡力相容但未驗證；不提供 ARM64 或 32 位元版本。
- **執行檔沒有數位簽章**：從網路下載後，Windows SmartScreen 可能顯示「Windows 已保護您的電腦」，需選擇「其他資訊」→「仍要執行」；部分企業環境可能禁止執行未簽章的程式。
- **沒有安裝程式與自動更新**：解壓縮即可使用；更新時以新版資料夾取代舊版，設定保留在 `%LocalAppData%\ScreenshotApp`。
- **單檔版第一次執行會寫入暫存資料夾**：單一執行檔版本把 WPF 的原生程式庫解壓到使用者暫存資料夾後才啟動；暫存資料夾不可寫入或受原則限制時無法啟動，請改用資料夾版本。
- **未預期錯誤的技術細節可能是英文**：檔案與設定的常見錯誤（沒有權限、找不到檔案或資料夾、檔案被占用、磁碟空間不足、路徑太長）以繁體中文說明；其他少見的錯誤會附上系統或 .NET 提供的原始訊息，可能是英文。

## 截圖

- **不擷取滑鼠游標**：截圖畫面中不會出現游標圖像。
- **受保護的內容**：播放受 DRM 保護的影片，或應用程式設定為「不允許被擷取」的視窗（例如部分密碼管理工具、會議軟體的分享保護），在截圖中可能呈現黑色或完全不出現。
- **安全桌面**：UAC 權限提示、登入畫面與 `Ctrl+Alt+Del` 畫面位於 Windows 的安全桌面，無法擷取；在這些畫面上按快捷鍵也不會有反應。
- **特殊 GPU 畫面**：獨佔全螢幕的遊戲、使用硬體覆蓋層播放的影片等，可能擷取為黑色畫面。
- **靜態快照**：按下快捷鍵的當下即凍結整個桌面，選取期間畫面上的動畫、影片或時鐘變化不會反映在截圖中。
- **自己的視窗**：截圖前會先隱藏 ScreenshotApp 自己的視窗（例如設定視窗），選取結束後再恢復；Windows 系統對話框（例如色彩對話框）開啟中時仍可能被截入。

## 區域選取

- **只能在單一顯示器內選取**：拖曳超出起始顯示器的部分會被限制在該顯示器的邊界內，無法一次選取橫跨多個顯示器的範圍。
- **選取期間變更顯示設定會取消截圖**：在選取時變更解析度、縮放比例或顯示器排列，或插拔顯示器，會取消本次截圖並顯示提示，需重新截圖。
- **只有矩形選取**：不支援自動偵測視窗或控制項邊界，也不支援任意形狀選取。
- **選取時的十字游標由程式繪製**：黑色十字外圍一圈白邊，在白、灰、黑等任何底色上都看得見；尺寸依顯示器 DPI 採用 Windows 的標準游標尺寸，不套用 Windows 協助工具中的指標色彩與樣式設定（指標大小設定是否套用尚未驗證）。
- **點一下不會產生截圖**：在原地按下並放開滑鼠（沒有拖曳）不會產生任何圖片，選取畫面會保留，可重新拖曳或按 `Esc`／滑鼠右鍵取消。

- **放大鏡與螢幕取色只讀靜態快照**：不讀取選取期間底下程式的新畫面；顯示器外的格子填中性灰，不複製邊緣像素。放大鏡格數與倍率固定，不支援方向鍵逐像素移動。
- **混合 DPI 實機驗收尚未完成**：幾何與未顯示覆蓋層的像素繪製已有自動化測試，實際鍵鼠操作、100%／125%／175%／200% 與多螢幕邊緣仍以驗收紀錄為準。

## 編輯與輸出

- **沒有可重新編輯的專案格式**：複製或另存的圖片已將標註與底圖合併，是最終成品；關閉編輯器後無法再回到可個別修改標註的狀態。
- **沒有修改的圖片不會詢問**：只有加入標註、裁切等修改且尚未複製或儲存時，新截圖、開啟其他圖片、關閉編輯器或結束程式才會詢問；剛截取或剛開啟、沒有任何修改的圖片會直接被取代或關閉。
- **確認期間繼續編輯**：在關閉或切換文件的提示中選擇複製／儲存後，若背景匯出期間又新增修改，原操作會中止並保留文件；完成編輯後需重新要求關閉或切換。
- **登出或關機**：有尚未複製或儲存的修改時，ScreenshotApp 會暫停登出或關機並詢問；處理後需重新登出或關機。若在 Windows 的提示畫面選擇仍要登出或關機，這些修改會遺失。
- **剪貼簿被其他程式占用**：複製時 Windows 剪貼簿正被其他程式開啟，會自動重試約 1～2 秒，期間編輯器暫時沒有回應；仍失敗時顯示原因，圖片仍保留在編輯器中。
- **一次只能選取一個標註**：不支援框選或 Shift 多選，移動、刪除與調整樣式都針對單一標註。
- **矩形與橢圓只有外框可以點選**：點在框線內側的空白處會選到下方的標註，與簡報軟體的空心圖形相同。
- **文字不會自動換行**：只依輸入時按下的 `Enter` 分行；文字超出裁切範圍的部分不會出現在輸出中。
- **字型只提供基本選項**：微軟正黑體、新細明體、標楷體、Segoe UI、Consolas；選擇的字型只在編輯視窗開著時沿用，關閉編輯視窗後回到微軟正黑體；顏色、線寬與字級才會記住到下次啟動。
- **縮小檢視時的顯示**：縮放低於 100% 時畫面以高品質縮小，細線與小字可能看起來較淡；輸出不受影響。
- **裁切後的放大最多 400%**：套用裁切後畫布放大到填滿畫布，但最大 400%；很小的裁切範圍（寬與高都不到畫布的四分之一）不會完全填滿。放大比例通常不是整數，畫面上部分像素會寬一個螢幕像素；輸出不受影響。
- **復原裁切不回到裁切前的檢視**：復原裁切或「還原完整圖片」後，畫布對整張圖片重新符合視窗，不會回到裁切前手動設定的縮放比例與捲動位置。
- **再製的複本只能放在一個方向**：複本往右下偏移 10 像素，某個方向會超出裁切範圍時改往反方向；標註比裁切範圍還寬或還高時，複本仍可能有一部分在裁切範圍外。

## 馬賽克與模糊（開發版）

- **不保證保密**：模糊可能被辨識或部分還原；馬賽克強度不足時也可能保留可辨識內容。優先使用馬賽克降低細節並檢查匯出，不能視為刪除原始資料。
- **原圖仍在文件內**：效果非破壞性，可復原；預設開啟的磁碟歷史也會保留原圖（可在設定關閉與清除）。PNG／剪貼簿只攜帶合成影像。
- **只取樣原圖**：不模糊或馬賽克下層標註的像素，而是以原圖效果不透明蓋住它們；上層標註仍會顯示。區域移動後重新取樣新位置的原圖。
- **大範圍重算會短暫阻塞 UI**：4K 3840×2160、Release、單一 STA 執行緒、5 次移動邊界量測，馬賽克 12px 中位數約 51ms，模糊半徑 6px 約 424ms；含取樣與點陣圖建立，不含畫面呈現或輸出編碼。詳見 [量測條件與原始值](evidence/phase-10/performance.json)。不能宣稱大範圍拖曳流暢；實機操作尚未驗證。
- **快取有上限**：每張仍存活原圖最多 8 筆／64 MiB 結果，超過 64 MiB 的單一效果不快取；巨大圖片會需要較多暫時記憶體與重算時間。

## 開啟圖片

- **載入期間繼續編輯**：背景解碼期間若在原文件新增尚未匯出的修改，這次開圖會中止並保留原文件；完成編輯後需重新開啟圖片。
- **只支援 PNG、JPEG、BMP**：依檔案內容判斷格式，與副檔名無關；GIF、TIFF、WebP、HEIC 等格式無法開啟。
- **尺寸上限**：寬 × 高超過 1 億像素的圖片會拒絕開啟，避免記憶體不足或程式沒有回應。
- **裁切不減少匯出的工作量**：複製或另存時一律先合成整張圖片再取出裁切範圍（確保裁切不改變範圍內的像素），因此很大的圖片即使只保留一小塊，每次匯出仍需要整張圖片大小的暫時記憶體（1 億像素約 400 MB）與時間。
- **透明度以白色背景合成**：含透明度的 PNG 開啟後透明的部分變成白色，複製與另存的結果都不保留透明度；如此剪貼簿的點陣圖格式（不支援透明度）與 PNG 才會一致。
- **不套用相片的方向資訊**：相機或手機照片中記錄的旋轉方向（EXIF）不會套用，直拍的照片可能以橫向顯示。
- **不套用色彩描述檔**：圖片中內嵌的色彩描述檔（ICC）不會轉換，像素值依檔案原樣使用。
- **只缺後段影像資料的檔案仍可開啟**：PNG 或 JPEG 若在影像資料中途被截斷，Windows 的解碼器會以黑色補足缺少的部分而不回報錯誤；完全無法辨識或結構損壞的檔案才會顯示無法開啟。
- **另存不會覆寫來源檔案**：另存的預設檔名一律是新的 `Screenshot_…png`；只有在存檔對話框中選擇原檔案並確認覆寫時才會取代它。

## 尺規與編輯器取色

- 長度是原圖／快照的像素中心距離，不換算公分；外接寬高包含端點，因此長度與寬高可能相差一像素。
- 覆蓋層量測限起始顯示器，只讀凍結快照；放開不截圖，必須按 R 回到區域選取後再選範圍。
- 尺規標籤固定白底黑字、字級隨線寬變化，會蓋住線段中央的小範圍；極小圖片中縮小，裁切可能裁掉標籤，不會重新定位。
- 編輯器取色只讀原圖，不讀合成標註或效果。透明來源轉成非預乘 RGB，完全透明像素的隱藏 RGB 依來源格式而定。
- 本階段真實鍵鼠、PrintWindow、混合 DPI、微軟注音組字中暫時取色與 PowerPoint 貼上尚未驗證；自動化的隱藏視窗與合成像素測試不能取代實機驗收。

## 目前開發版尚未提供的功能

影片／GIF 錄製、跨螢幕單次選框、指定視窗自動偵測、OCR、QR Code、實色遮蔽、圖片釘選、圖層群組、多人協作、雲端服務、帳號、外掛、完整多語系切換與自動更新。

## 截圖歷史（v1.2 開發版）

- 原圖與標註未加密，包含裁切及遮蔽之前的內容；關閉歷史不會刪除舊條目。請從歷史視窗或設定確認「全部清除」。清除不是安全抹除，不保證移除作業系統或備份副本。
- 縮圖顯示原始截圖；重新開啟或複製才合成完整標註與裁切。保留上限以筆數計算，沒有磁碟容量配額；大量大圖仍可能占用相當空間。
- 不保存復原堆疊、拖曳預覽與尚未提交的文字輸入；文件取代或關閉前會先提交文字。開啟既有圖片、關閉歷史期間的內容不補存。
- JSON 是內部格式，未知版本／種類或無效值只還原原圖並提示，不自動覆寫原條目。原圖損毀不可開啟，可用全部清除移除。歷史位置不支援符號連結或接合點。
- 結束時最多等待 3 秒；系統強制終止或逾時可能遺失最新更新。不完整條目於下次啟用歷史啟動維護時清理。停用歷史不進行維護或淘汰。
- 實際首次通知、長時間常駐、重新啟動、UI 鍵鼠操作與磁碟占用尚未驗證；自動化使用暫存目錄，詳見 [驗收紀錄](ACCEPTANCE.md)。

## 長截圖（v1.2 開發版）

- 只支援單一顯示器內的垂直向下拼接。往回捲動不附加，捲動過快而沒有可靠重疊時保留前段並提示；重複圖樣不猜測位移。
- 只接受逐像素一致的重疊；平滑捲動須等畫面停穩，影片、動畫、閃爍游標、變動的捲軸、浮動元件及變化的標頭可能阻止拼接。建議縮小選框，避開這些區域。不能保證任意網頁或文件可拼接。
- 自動模式使用定向滾輪訊息；Edge、Chrome、Word、VS Code、檔案總管與已知圖樣的實際操作尚未驗證。忽略訊息、權限較高或特殊輸入處理的程式可能不動，請改手動。不會自動回退到全域輸入，也不會移動你的游標。
- 自動捲動每次只送一格；至少三張相同影格才拼接。輸入以輪詢及每次發送前檢查，不能保證零延遲偵測。開始自動時請先放開按鍵，以滑鼠按按鈕；有輸入後回到手動。全域 Esc 不攔截，面板有焦點時才可用 Esc 取消。
- 固定首尾帶由影格推算，要求之後保持不變；過大的固定帶、均勻色或重複內容可能無法可靠辨認。停止自動不代表長截圖已完成，仍可手動或按完成。
- 高度最多 32,768 像素，總計最多 100,000,000 像素；初始影格超限拒絕，後續只收納上限內完整列。巨大結果仍可能需要大量記憶體，建議分段；記憶體不足會取消並恢復舊文件。
- 控制面板沒有足夠框外空間時會在取樣前隱藏，可能閃爍。範圍中心的原視窗被遮住或關閉時取消；擷取期間避免切換應用程式或移動目標視窗。DRM、UAC 與特殊 GPU 的限制同一般截圖。
- 完成結果依歷史設定保存；取消與失敗不保存。自動化測試通過不代表 MT-13 或桌面逐像素驗收已通過，見[驗收紀錄](ACCEPTANCE.md)。
