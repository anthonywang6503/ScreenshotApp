# 已知限制

本文件列出 ScreenshotApp v1.0 已知的功能限制與不支援的情境。內容隨開發進度補充，正式版發佈前會再完整檢查一次。

## 截圖

- **不擷取滑鼠游標**：截圖畫面中不會出現游標圖像。
- **受保護的內容**：播放受 DRM 保護的影片，或應用程式設定為「不允許被擷取」的視窗（例如部分密碼管理工具、會議軟體的分享保護），在截圖中可能呈現黑色或完全不出現。
- **安全桌面**：UAC 權限提示、登入畫面與 `Ctrl+Alt+Del` 畫面位於 Windows 的安全桌面，無法擷取；在這些畫面上按快捷鍵也不會有反應。
- **特殊 GPU 畫面**：獨佔全螢幕的遊戲、使用硬體覆蓋層播放的影片等，可能擷取為黑色畫面。
- **靜態快照**：按下快捷鍵的當下即凍結整個桌面，選取期間畫面上的動畫、影片或時鐘變化不會反映在截圖中。
- **自己的視窗**：截圖前會先隱藏 ScreenshotApp 自己的視窗（例如設定視窗），選取結束後再恢復；Windows 系統對話框（例如色彩對話框）開啟中時仍可能被截入。

## 區域選取

- **只能在單一顯示器內選取**：拖曳超出起始顯示器的部分會被限制在該顯示器的邊界內，無法一次選取橫跨多個顯示器的範圍。
- **選取期間變更顯示設定會取消截圖**：在選取時變更解析度、縮放比例或顯示器排列，或插拔顯示器，會取消本次截圖並顯示提示，需重新截圖。
- **只有矩形選取**：不支援自動偵測視窗或控制項邊界，也不支援任意形狀選取。
- **點一下不會產生截圖**：在原地按下並放開滑鼠（沒有拖曳）不會產生任何圖片，選取畫面會保留，可重新拖曳或按 `Esc`／滑鼠右鍵取消。

## 編輯與輸出

- **沒有可重新編輯的專案格式**：複製或另存的圖片已將標註與底圖合併，是最終成品；關閉編輯器後無法再回到可個別修改標註的狀態。

## v1.0 不提供的功能

影片／GIF 錄製、長截圖、跨螢幕單次選框、指定視窗自動偵測、OCR、QR Code、取色器、尺規、馬賽克、模糊、實色遮蔽、圖片釘選、截圖歷史、圖層群組、多人協作、雲端服務、帳號、外掛、完整多語系切換與自動更新。
