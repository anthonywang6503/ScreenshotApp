### Phase 1 驗證步驟（MT-01、MT-02 占用提示）

### Phase 2 驗證步驟（MT-02 觸發、MT-04、MT-05；MT-03 的取消部分）

執行檔同上。Phase 2 選取完成後會**直接複製到剪貼簿**並以系統通知顯示尺寸（編輯器於 Phase 3 接上）。

> 以 Phase 3 之後的版本驗證時，選取完成會改為開啟編輯器：下列步驟中的「通知顯示的尺寸」改看編輯器狀態列的「圖片：W × H」，「剪貼簿中的截圖」改為在編輯器按 `Ctrl+C` 後再貼上。

1. **MT-02（觸發截圖）**：分別讓桌面、瀏覽器、PowerPoint 位於前景，按 `Ctrl+Shift+2`：畫面應立即凍結並變暗；拖曳選取後放開，通知顯示「已將 W × H 像素的截圖複製到剪貼簿」，在 PowerPoint 或小畫家貼上應得到選取的畫面。之後在設定視窗改用其他快捷鍵，再重複一次。
2. **MT-03（取消部分）**：按 `Esc` 或滑鼠右鍵，所有變暗的畫面立即消失，剪貼簿內容不變；在原地點一下（沒有拖曳）不會產生截圖，畫面維持在選取狀態。
3. **MT-04（單螢幕各縮放）**：在「設定 → 系統 → 顯示器 → 縮放」分別設為 100%、125%、150%、200%，每種縮放下：
   - 變暗的畫面完整蓋住螢幕，邊緣沒有未變暗的縫隙，畫面內容與原本的位置完全重合（沒有放大、縮小或位移）。
   - 選取一個已知寬度的物件，選取框旁的尺寸、通知中的尺寸與貼上後的圖片尺寸一致，且內容正是選取框內的畫面。
   - 也可以執行 `pwsh -File tools\smoke\Invoke-Phase3Smoke.ps1 -Cycles 3`（開始前需閒置 60 秒；執行期間請勿操作滑鼠鍵盤，偵測到操作會自動停止）：前幾項會確認編輯器在 100% 時與截圖逐像素一致，可用來檢查各縮放下的尺寸與位置。`Invoke-Phase2Smoke.ps1` 已改為從編輯器以「複製」按鈕取得截圖結果，也可以在 Phase 3 之後的版本執行。
4. **MT-05（雙螢幕）**：測試兩個顯示器縮放不同（例如 100% 與 150%）、第二個顯示器在主螢幕左側（負 X 座標）、上下排列，並在非主螢幕上截圖：
   - 每個顯示器都會變暗且完整貼合；在任一顯示器拖曳都能選取，拖到另一個顯示器時選取框停在起始顯示器的邊緣。
   - 貼上的圖片內容與選取框一致、沒有偏移或縮放，尺寸與通知一致。
   - 煙霧腳本會檢查每個顯示器覆蓋層的邊界與 DPI；圖樣比對只在主螢幕進行。

### Phase 3 驗證步驟（MT-03 編輯器部分、MT-06、MT-07）

執行檔同上。編輯器的操作說明見 [使用說明](USER_GUIDE.md#編輯器)。（以下為 Phase 3 當時的說明：當時尚未提供未匯出變更提醒，新截圖會直接取代編輯中的圖片，關閉編輯器會直接捨棄標註；Phase 4 起會先詢問。）

1. **MT-03（開啟編輯器、取消不影響先前文件）**：
   - 按 `Ctrl+Shift+2` 拖曳選取後放開：編輯器開啟並位於前景，圖片以符合視窗（不超過 100%）顯示，狀態列「圖片」的尺寸與選取框旁的尺寸相同。
   - 在圖片上畫一個矩形，再按 `Ctrl+Shift+2`：編輯器暫時隱藏、畫面變暗；按 `Esc` 取消後，編輯器回來且矩形仍在。
   - 再截一張圖：同一個編輯器改為顯示新的截圖（舊的圖片與矩形被取代）。
2. **MT-06（微軟注音）**：
   - 選「文字」工具，在圖片上點一下，切換到微軟注音輸入「測試中文輸入」（包含選字），按 `Enter` 換行後再輸入第二行，按 `Ctrl+Enter` 完成：文字停在輸入時的位置，沒有跳動、缺字、重複或錯字。
   - 組字中（注音符號還沒選字）按 `Esc`：只取消組字，文字框仍在編輯中。
   - 選取部分已輸入的文字按 `Ctrl+C`，到記事本貼上：貼上的是文字，而不是整張圖片。
   - 用「選取」工具雙擊文字重新編輯，在中間以注音插入幾個字後按 `Ctrl+Enter`：內容正確；按 `Ctrl+Z` 回到修改前、`Ctrl+Y` 再回到修改後。
   - 在屬性列變更字級、顏色與字型：輸入中的文字立即套用，輸入框維持在編輯狀態。
3. **MT-07（多縮放一致性）**：
   - 加入文字、箭頭、矩形與兩個步驟編號後按 `Ctrl+C`，貼到小畫家或 PowerPoint 作為對照。
   - 以 `Ctrl+滾輪` 縮放到 25%：拖曳移動矩形，再按 `Ctrl+Z` 復原；縮放到 400%：拖曳箭頭端點後 `Ctrl+Z` 復原。回到 100%（`Ctrl+0`）再按 `Ctrl+C` 貼上：與對照圖完全相同。
   - 在 25% 與 400% 時直接按 `Ctrl+C` 貼上，或以 `Ctrl+S` 另存 PNG：圖片尺寸都等於狀態列的「裁切」尺寸，標註的位置、線寬與字級都與 100% 時相同。
   - 也可以執行 `pwsh -File tools\smoke\Invoke-Phase3Smoke.ps1 -Cycles 3`（開始前需閒置 60 秒；執行期間請勿操作滑鼠鍵盤，偵測到操作會自動停止），所有項目應為 PASS。

### Phase 4 驗證步驟（MT-08 重新確認、MT-09、十字游標與未匯出變更）

執行檔同上（先從系統匣結束正在執行的 ScreenshotApp，再執行 `dotnet build ScreenshotApp.sln -c Release`）。

1. **十字游標（使用者回報的問題）**：讓全白的畫面（例如最大化的空白記事本）在前景，按 `Ctrl+Shift+2`：變暗的畫面上十字游標是黑色十字加白色外框，清楚可見；在深色畫面上顯示為白色外框。拖曳選取時，十字中心對準的像素就是選取的起點。
2. **MT-08（剪貼簿改為 PNG 與點陣圖兩種格式，需重新確認）**：截圖並加上矩形與文字後按 `Ctrl+C`，分別貼到 PowerPoint、Word 與 Teams；再按 `Ctrl+S` 另存 PNG，把這個 PNG 插入同一份 PowerPoint，與貼上的圖片並排比對：尺寸與內容相同。
3. **MT-09（錯誤恢復）**：
   - 磁碟不可寫：另存時選擇唯讀的檔案或沒有寫入權限的資料夾，Windows 的存檔對話框會先拒絕並說明原因（唯讀檔已由煙霧驗證確認）；若到寫入時才失敗（例如磁碟已滿、檔案被其他程式鎖住、隨身碟被拔除），ScreenshotApp 顯示「無法儲存圖片」與原因。兩種情況圖片與標註都仍在編輯器中，可以改存到其他位置。
   - 剪貼簿被占用：執行 `pwsh -File tools\smoke\Invoke-Phase4Smoke.ps1`（會自動模擬占用），或在其他程式長時間占用剪貼簿時複製：約 1～2 秒後顯示「剪貼簿正被其他程式使用」，圖片仍在編輯器中。
   - 顯示器中途拔除：選取期間拔除或關閉第二個顯示器：所有變暗的畫面消失並提示，之後可以再次截圖（需要實體雙螢幕）。
4. **未匯出變更保護**（請確認行為符合預期）：截圖後加一個矩形，然後分別 (a) 再按截圖快捷鍵、(b) 按編輯器的「開啟」或 `Ctrl+O`、(c) 關閉編輯器、(d) 系統匣「結束」：都會先詢問「圖片有尚未複製或儲存的變更」，選「另存 PNG 後繼續」「複製後繼續」「捨棄變更」會繼續原本的操作，選「取消」或按 `Esc` 什麼都不變。沒有任何修改的截圖不會詢問；若希望未修改的截圖也要詢問，請告知。
5. **開啟圖片**：系統匣「開啟圖片」或編輯器「開啟」開啟 PNG、JPEG、BMP；開啟損壞的檔案（或把文字檔改名為 .png）時顯示無法開啟的原因，原本的圖片不變。
6. **Delete 鍵（Phase 5 已查明自動化驗證的失敗是腳本判定錯誤，Delete 正常；歡迎以實體鍵盤確認一次）**：截圖後畫一個箭頭，切換到「選取」工具點一下箭頭（出現控制點），按鍵盤的 `Delete`：箭頭應該被刪除，再按 `Ctrl+Z` 應該恢復。若沒有刪除，也請試試「點一下空白處取消選取、再點一次箭頭」或「在箭頭上按右鍵選『刪除』」是否有效。
7. 以上自動化部分可執行 `pwsh -File tools\smoke\Invoke-Phase4Smoke.ps1`（開始前需閒置 60 秒；Phase 5 起預設包含 30 次完整循環與延遲量測，約 8～10 分鐘，加上 `-Cycles 0` 可只做功能檢查；執行期間請勿操作滑鼠鍵盤，偵測到操作會自動停止）。

### Phase 5 驗證步驟（發佈版、MT-11 與尚未回報的項目）

發佈版由 `pwsh -File tools\Publish-Release.ps1` 產生在 `publish\`。驗證前先從系統匣結束其他正在執行的 ScreenshotApp。

1. **發佈版（資料夾版）**：把 `publish\ScreenshotApp-1.0.0-win-x64.zip` 解壓縮到任意資料夾，執行其中的 `ScreenshotApp.exe`：系統匣出現圖示；按 `Ctrl+Shift+2` 截圖、畫一個箭頭與一段中文、按 `Ctrl+C` 貼到小畫家、按 `Ctrl+S` 另存 PNG；從系統匣結束。
2. **單檔版**：對 `publish\ScreenshotApp-1.0.0-win-x64-singlefile.zip` 重複第 1 步，並確認檔案總管中 `ScreenshotApp.exe` 顯示藍色截圖圖示。
3. **MT-11（乾淨機器）**：在沒有安裝 .NET 的 Windows 11 x64（例如新安裝的虛擬機器，或啟用「Windows 沙箱」功能後在沙箱中）重複第 1 步。執行前可在命令提示字元輸入 `dotnet --list-runtimes`，若顯示找不到指令或沒有 `Microsoft.WindowsDesktop.App`，即為沒有 .NET Runtime 的環境。
4. **Delete 鍵**：見「Phase 4 驗證步驟」第 6 步，請以實體鍵盤確認一次。
5. **尚未回報的項目**：MT-04、MT-05 見「Phase 2 驗證步驟」第 3、4 步；MT-07 見「Phase 3 驗證步驟」第 3 步；MT-08（剪貼簿改為 PNG 與點陣圖後重新確認）、MT-09 與十字游標見「Phase 4 驗證步驟」第 1～3 步。可以使用發佈版驗證。
6. **MT-10（資源趨勢）**：Agent 端已以 30 次完整循環量測（見第 2 節）；如需自行確認，可在電腦閒置時執行 `pwsh -File tools\smoke\Invoke-Phase4Smoke.ps1 -ExePath <解壓縮的資料夾>\ScreenshotApp.exe`，結果的「GDI 物件數沒有成長」「USER 物件數沒有成長」應為 PASS。
