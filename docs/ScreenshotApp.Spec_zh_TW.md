## 1. 問題、目標與完成定義

使用者需要一套**不依賴雲端的 Windows 輕量截圖工具**。程式常駐系統匣，以快捷鍵選取畫面，截圖後立即開啟圖片編輯器，加入方框、箭頭、文字、步驟編號或裁切，再將成品貼入 PowerPoint、Word、Teams，或存為 PNG。

### 必須維持的基本工作流程

**啟動常駐 → 快捷鍵 → 桌面快照 → 區域選取 → 圖片編輯 → 複製或另存 PNG**

v1.2 另提供選取時放大與取色、量測、效果與尺寸標註、歷史重新開啟，以及獨立入口的長截圖。一般區域截圖仍於放開滑鼠後立即進入編輯。

### 成功標準

1. 完整工作流程可在 Windows 11 x64 實際操作，不需要系統管理員權限、帳號、伺服器或網路。
2. 螢幕選取與最終匯出圖片在實體像素上範圍正確，沒有 DPI 造成的偏移。
3. 標註可選取、移動、修改、刪除、Undo／Redo；原始底圖在編輯工作階段中不受破壞。
4. PNG 與剪貼簿圖片內容一致，且已實際驗證可貼入 PowerPoint；Word 與 Teams 完成相容性檢查。
5. 提供 `win-x64` 自包含式可攜版本，不必額外安裝 .NET Runtime。
6. 核心座標、裁切、標註與編輯歷史具備自動化測試；Windows 操作流程具備驗收紀錄。

## 2. 不得變更的技術與產品決策

1. 使用 **C#、.NET 10 LTS、WPF、Win32 API**，目標框架為 `net10.0-windows`，採用穩定版 .NET 10 SDK。
2. 完全本機離線運作。不採用 Electron、Tauri、WebView、Python Runtime、資料庫、Web Server、微服務或雲端 API。
3. 截圖使用 GDI `BitBlt` 實作靜態桌面快照；長截圖以同一技術重複擷取選定範圍後拼接，不導入 DXGI 或 Windows.Graphics.Capture。
4. 快捷鍵以 `RegisterHotKey`／`WM_HOTKEY` 實作，不使用全域低階鍵盤或滑鼠 Hook；長截圖的自動捲動與使用者輸入偵測也須遵守。
5. 啟用 Per-Monitor V2 DPI Awareness。螢幕、裁切與圖片模型以實際像素座標為唯一真值；WPF DIP 只用於顯示與互動。
6. 圖片編輯採用 **原始 Bitmap + 標註物件 + 非破壞性裁切 + Command Pattern**。標註包含向量標註與以原圖產生的像素效果，兩者都不得修改原圖。
7. Windows System Tray 可使用 Windows Forms `NotifyIcon`，主要 UI 一律使用 WPF。
8. 同一時間只開啟一份編輯文件。切換文件時需保護未匯出的變更。
9. v1.0 使用台灣繁體中文介面。文字資源集中管理，保留未來增加英文的可能性。
10. 採用單一 WPF 可執行專案與一個測試專案，不因抽象化而無意義地拆分多個類別庫。

## 3. 使用者故事

1. 作為使用者，我希望工具開機後常駐系統匣，隨時可截圖，而不占用主畫面。
2. 作為使用者，我希望按下快捷鍵、拖曳選取區域，立即取得正確圖片。
3. 作為使用者，我希望在不同 DPI 的多螢幕環境下截圖，不發生像素偏移。
4. 作為使用者，我希望加入、修改與移動方框、箭頭、線條、文字及步驟編號，用於簡報解說。
5. 作為使用者，我希望能重新裁切、復原或重做操作，而不是整張圖片重來。
6. 作為使用者，我希望一鍵複製圖片貼到 PowerPoint，或手動另存 PNG。
7. 作為使用者，我希望開啟本機既有圖片進行同樣編輯，而不只限新截圖。
8. 作為使用者，我希望快捷鍵衝突、檔案寫入失敗或剪貼簿忙碌時收到明確提示，而且不遺失正在編輯的圖片。
9. 作為使用者，我希望可以控制開機啟動，正常結束時解除快捷鍵並釋放資源。

## 4. 功能需求（含 v1.2 新增項目）

以下均為強制需求，每一項皆須具有對應的驗收方式。

### 4.1 系統常駐、快捷鍵與生命週期

**FR-01 系統匣常駐**

程式啟動後直接進入系統匣，不顯示主視窗。系統匣選單至少包含「開始截圖」「長截圖」「截圖歷史」「開啟圖片」「設定」「結束」。新增入口隨對應功能實作交付，不提供無法操作的占位項目。

**FR-02 全域快捷鍵**

預設使用 `Ctrl + Shift + 2`，允許在設定畫面修改。採用 `MOD_NOREPEAT` 避免長按重複觸發。

**FR-03 快捷鍵衝突處理**

無法註冊快捷鍵時，程式與系統匣仍須可用，並顯示失敗原因。變更快捷鍵須先確認新組合成功註冊，再解除舊組合，保留最後一次成功設定。

**FR-04 單一執行個體**

不得產生兩組系統匣圖示或重複註冊快捷鍵。再次啟動時通知既有執行個體，顯示其設定或編輯視窗。

**FR-05 開機啟動**

提供「登入 Windows 時啟動」開關，透過目前使用者層級設定（例如 `HKCU\...\Run`）完成。預設關閉，不要求管理員權限。

**FR-06 正常結束**

結束時解除快捷鍵、移除系統匣圖示、關閉遮罩與長截圖視窗及釋放 GDI 資源。存在未匯出變更時，須先確認；歷史待寫入工作依 FR-42 有限等待並回報失敗。

### 4.2 截圖及區域選取

**FR-07 截圖順序**

截圖前先隱藏應用程式可能覆蓋桌面的視窗，取得各顯示器桌面快照，再顯示區域選取遮罩。不得截入自己的選取遮罩或編輯器。

**FR-08 區域選取**

各顯示器均有可操作的覆蓋層。滑鼠可拖曳選取單一顯示器內的矩形，遮罩外區域變暗，選取範圍清楚顯示，並標示實際像素寬高。

**FR-09 多螢幕與 DPI**

必須支援負的桌面 X／Y 座標、非主螢幕、不同解析度與不同縮放比例。v1.0 選取範圍限於單一顯示器，拖曳超過邊界時應限制在起始顯示器內。

**FR-10 取消選取**

零寬、零高選取不得產生文件。按 `Esc` 或滑鼠右鍵取消並返回先前狀態；原本在編輯時恢復原文件與視窗，不建立空白文件或檔案。

**FR-11 自動進入編輯**

一般區域截圖完成有效選取後，立即關閉所有遮罩並開啟獨立圖片編輯器，不需額外確認。從獨立入口開始的長截圖依 FR-43 進入捲動工作階段；取色與量測依 FR-38、FR-41 處理，不建立截圖文件。

**FR-12 擷取失敗處理**

擷取失敗、螢幕拔插或顯示設定在選取期間改變時，應安全取消並顯示錯誤，不留下全螢幕遮罩。

**FR-13 已知擷取限制**

v1.0 預設不擷取滑鼠游標圖像。DRM 保護內容、UAC 安全桌面及部分特殊 GPU 畫面可能無法擷取，須在文件明確說明。

### 4.3 圖片編輯器

**FR-14 編輯器介面**

編輯器提供工具列、圖片畫布、屬性控制、複製／儲存按鈕及狀態列。新截圖自動以適合視窗的縮放比例顯示。在畫布上按滑鼠右鍵開啟依情境的快顯選單（FR-36）。

**FR-15 編輯工具**

必須提供十二種工具：選取／移動、裁切、矩形、橢圓、直線、箭頭、文字、步驟編號、馬賽克、模糊、尺規、取色。取色為一次性操作，不建立標註。

**FR-16 非破壞性標註**

標註為獨立物件，支援選取、移動、調整尺寸或端點、修改適用的樣式、刪除及調整前後層順序。一般標註可修改顏色與線條粗細；馬賽克與模糊改以強度控制，顏色與線寬對它們不適用。不得在每次標註時直接修改原始 Bitmap。

另支援：

- **再製**：複本與原標註的樣式相同、位於最上層並成為選取，位置向右、向下各偏移 10px；某個方向會超出目前顯示的裁切範圍時改往反方向偏移。步驟編號的複本取下一個編號。
- **反轉箭頭方向**：箭頭的起點與終點對調。
- **清除所有標註**：一次刪除全部標註。

**FR-17 文字標註**

支援微軟注音、台灣繁體中文、英文、Unicode、換行；完成輸入後可以雙擊重新編輯，並修改字級、顏色及基本字型。文字建立或完成修改視為一筆 Undo 操作。

**FR-18 步驟編號**

依建立順序自動產生 `1、2、3...` 的圓形編號標記。標記可移動、調整大小及修改數值。刪除編號時不自動重排其他既有編號；使用者要求「重新編號所有步驟」時，才依現有編號由小到大重排為 `1、2、3...`，編號相同者依前後層順序（較底層者在前）。

**FR-19 樣式設定**

提供常用顏色與自訂顏色選擇；預設線條紅色、3px，文字 20px。尺寸皆以最終圖片像素為準，不隨畫布縮放比例改變。

**FR-20 裁切**

裁切採用非破壞性的 `CropRect`，不修改原始 Bitmap。允許重複調整並支援 Undo／Redo，最小裁切區域 `1×1px`，不可超出原圖。可一次「還原完整圖片」，把裁切範圍設回整張原圖。

**FR-21 畫布縮放**

支援符合視窗、100%，以及 25%～400% 縮放與平移。縮放、平移或調整編輯器視窗，都不得改變輸出的標註位置、字級與線寬。

裁切後畫布只顯示裁切範圍，並以裁切範圍填滿畫布：

- 「符合視窗」顯示整張圖片時不超過 100%，小圖維持原尺寸；只顯示裁切範圍時可放大到 400%。
- 套用、復原、重做或還原完整圖片使顯示的裁切範圍改變時，畫布回到符合視窗。只進出裁切工具而沒有改變範圍時，維持原本的縮放。
- 復原裁切時文件回到裁切前的狀態，畫布對恢復的範圍重新符合視窗，不還原裁切前的縮放比例與捲動位置。

**FR-22 操作歷史**

以 Command Pattern 實作 Undo／Redo，涵蓋新增、刪除、移動、調整大小、修改樣式、文字與裁切。一次連續滑鼠拖曳只記錄一筆操作；一次作用於多個標註的操作（清除所有標註、重新編號所有步驟）也只記錄一筆。預設最多保留 100 筆，不儲存每一步的完整 Bitmap 快照。

**FR-23 文件切換與未匯出變更**

同時僅開啟一份文件。若內容自最後一次成功匯出後曾修改，使用者要求一般／長截圖、開啟其他圖片或歷史、關閉或結束時，必須提供複製、儲存、捨棄或取消等明確選擇，不得無聲丟棄資料。

**FR-24 開啟既有圖片**

支援開啟 PNG、JPEG、BMP 並載入相同編輯器，匯出格式仍預設 PNG。未取得明確確認不得覆寫來源檔案。

**FR-25 編輯器與選取覆蓋層快捷鍵**

至少支援：

- `Ctrl+Z`：復原
- `Ctrl+Y`：重做
- `Ctrl+C`：複製最終圖片
- `Ctrl+S`：另存 PNG
- `Delete`：刪除選取的標註
- `Ctrl+D`：再製選取的標註
- `Esc`：取消目前選取或工具操作

正在編輯文字時，`Ctrl+C` 應優先遵循文字編輯行為，避免破壞輸入法組字。

選取覆蓋層另支援按住 `Ctrl` 顯示放大鏡、`C` 複製游標色碼、`R` 切換量測／區域選取、`Esc` 取消；這些未搭配修飾鍵的字母只在覆蓋層內作用，不攔截編輯器的文字輸入。觸發截圖時仍按著的 Ctrl 必須放開再按下，才顯示放大鏡。長截圖全域快捷鍵預設未設定，可由設定指定，不得與一般截圖使用相同組合。

**FR-36 右鍵選單**

v1.0.0 發佈後新增，編號接續既有需求。在畫布上按滑鼠右鍵，依位置與目前工具開啟對應的快顯選單。每個項目都有存取鍵，有快捷鍵的項目標示快捷鍵。可否執行取決於文件的項目（復原、重做、複製、另存 PNG、還原完整圖片、清除所有標註、重新編號所有步驟）在無法執行時停用。只適用於特定種類標註的項目，只在該種類上顯示。

- **標註上**（先選取該標註）：編輯文字（文字）、修改編號（步驟編號）、再製、反轉箭頭方向（箭頭）、重新編號所有步驟（步驟編號）、調整前後層順序、刪除。
- **畫布空白處**（先取消選取）：復原、重做、複製、另存 PNG、縮放（符合視窗、100%、放大、縮小）、還原完整圖片（有裁切時）、清除所有標註（有標註時）。
- **裁切工具中**：套用裁切、取消裁切、還原完整圖片（有裁切時）。在裁切工具中還原完整圖片會一併捨棄未套用的範圍並回到選取工具。

編輯文字與修改編號的效果與雙擊該標註相同。

### 4.4 圖片合成、剪貼簿與檔案

**FR-26 單一圖片合成器**

PNG 與剪貼簿輸出統一透過同一個 `ImageRenderer`，合成原始 Bitmap、裁切範圍及全部標註。畫布顯示縮放比例不得影響輸出。

**FR-27 像素精確性**

輸出圖片寬高必須嚴格等於 `CropRect` 的實際整數像素寬高。圖形座標、字級及線寬依圖片像素呈現；裁切範圍之外的圖形不得出現在成品。

**FR-28 複製到剪貼簿**

按鈕或 `Ctrl+C` 可將合成後的 Bitmap 放入 Windows 剪貼簿。複製成功後顯示輕量提示，並保留編輯器及目前文件。

**FR-29 剪貼簿錯誤**

剪貼簿被其他程式占用時，應執行有限次短暫重試。若仍失敗，顯示錯誤並保留正在編輯的圖片，不得假裝成功。

**FR-30 儲存 PNG**

提供另存對話框，預設檔名為 `Screenshot_yyyyMMdd_HHmmss_fff.png`。初始位置使用圖片資料夾或上次成功儲存的位置，同名檔案需確認覆寫，寫入失敗不得丟失圖片。

**FR-31 圖片持久化範圍**

不儲存至雲端、不上傳圖片。圖片持久化僅限使用者明確另存，以及 FR-42 規定的本機截圖歷史（v1.2 起預設開啟，可關閉與清除）。完整顯示器快照、取消的截圖、取色、量測及開啟的既有圖片不得自動加入歷史；歷史關閉後不得新增或更新歷史內容。故障日誌一律不得記錄圖像、色碼或文字標註內容。

**FR-32 Office 相容性**

同份圖片透過複製或 PNG 存檔得到的可視像素必須一致。必須在實際 PowerPoint 中驗證貼上結果，並檢查 Word、Teams 可否接收圖片。

### 4.5 設定與使用介面

**FR-33 本機設定**

設定內容至少包含截圖快捷鍵、長截圖快捷鍵（預設未設定）、開機啟動、上次儲存位置、預設顏色及線寬，以及保留截圖歷史（預設開啟）、保留筆數（預設 50）。設定儲存在 `%LocalAppData%\ScreenshotApp\settings.json`。設定畫面顯示固定的歷史資料夾 `%LocalAppData%\ScreenshotApp\history\`，並提供須確認的「清除全部歷史」操作；本版不提供變更歷史位置的設定。保留筆數接受 1～500 的整數；舊設定缺少新欄位時使用預設值，個別無效欄位只回復該欄位。

**FR-34 設定異常恢復**

JSON 設定損毀、欄位無效或讀取失敗時，須安全回復預設值並提示，不得導致常駐程式完全無法啟動。

**FR-35 台灣繁體中文與操作性**

整體 UI 使用台灣繁體中文，提供標準快捷鍵、工具提示、可辨識的焦點與基本鍵盤導覽。圖示不能是識別功能的唯一方式。

### 4.6 v1.2 擷取輔助、效果與歷史

**FR-37 選取放大鏡**

在區域選取或量測模式中，重新按住 Ctrl 才顯示放大鏡，放開、取消或滑鼠捕捉遺失時隱藏。未拖曳及拖曳期間都隨游標更新，且只顯示於游標所在顯示器的覆蓋層。取樣來源為本次擷取的未暗化快照，不重新擷取即時桌面。

以奇數格取樣，中心格對應游標所在像素並加框；每格放大為整數個螢幕實體像素，以最近鄰顯示，不平滑混色。超出顯示器的格子填入中性色，不複製邊緣像素或改變取樣中心。顯示從該顯示器左上角 `(0,0)` 起算的像素座標與大寫 `#RRGGBB` 色碼；放大鏡預設在游標右下，靠近邊緣時翻轉並限制於該顯示器內。不得改變既有選取框、尺寸與完成／取消行為。方向鍵逐像素移動游標不在本版範圍。驗收：AT-11、MT-12。

**FR-38 取色器**

- **覆蓋層**：按 C 讀取游標所在快照像素的 RGB，以大寫 `#RRGGBB` 純文字寫入剪貼簿。先關閉所有覆蓋層，再複製並以系統匣通知色碼；不建立文件、不加入歷史，恢復先前文件與視窗。剪貼簿失敗依 FR-29 有限重試並提示原因，不宣稱成功。
- **編輯器**：選取「取色」後點擊原圖範圍內的像素，讀取原圖而非已合成標註或效果的顏色，沿用顏色清單的套用方式：作用於正在編輯的文字、可修改顏色的選取標註，或後續新增標註的預設顏色。選取標註的顏色變更可復原，沒有選取時只更新預設值；效果標註不套用顏色。狀態列顯示色碼，完成或按 Esc 取消後回到原本工具。畫布外點擊不得取到邊界內的替代像素。

驗收：AT-12、Phase 9 與 Phase 11 煙霧驗證。

**FR-39 馬賽克**

提供矩形效果標註，拖曳建立，零尺寸不建立；完成後最小為 1×1px。以效果矩形左上角為區塊起點，取原圖範圍內像素的 RGB 平均值填滿每個區塊；邊緣不完整區塊只平均實際包含的像素。區塊大小可調，範圍、預設值與整數平均的捨入方式須在 Phase 10 的 ADR 與測試中固定，且不寫入設定檔。

支援選取、移動、八個控制點調整、再製、層序、刪除與復原／重做；每次完整拖曳或強度修改只記錄一筆命令。取樣只用原圖，結果以不透明點陣圖依標註層序覆蓋，因此也蓋住下方標註；上方標註仍依序繪製。顏色與線寬控制對此效果停用。畫面與輸出共用繪製碼，先合成整張原圖再裁切。

匯出 PNG 與剪貼簿只含合成結果，不附帶原圖、可編輯標註或復原資料。均勻區塊處理後可與原色相同，不以「每個像素都改變」判定效果；馬賽克不保證所有強度下都無法辨識內容。驗收：AT-04、AT-05、AT-07、AT-13、MT-14。

**FR-40 模糊**

提供與 FR-39 相同互動方式的矩形效果標註，強度為模糊半徑，不寫入設定檔。以三次可分離盒狀模糊近似高斯，只取樣效果範圍內的原圖像素，不取樣下層標註；每次運算在邊界只使用範圍內的像素並重新計算權重。半徑範圍、預設值與捨入方式須在 Phase 10 的 ADR 與測試中固定。非破壞性、層序、不透明覆蓋、命令與輸出規則同 FR-39。

操作說明必須明示模糊不保證敏感資訊無法辨識或還原；需要降低內容可辨識度時優先使用馬賽克並檢查匯出結果。兩者的原圖仍存在編輯文件與已啟用的截圖歷史中，不能把效果標註視為刪除原始資料。驗收：AT-13、MT-14。

**FR-41 尺規與截圖時量測**

- **共用量測定義**：端點是整數像素位置；Δx、Δy 為終點減起點，長度為兩個像素中心的歐氏距離 `sqrt(Δx² + Δy²)`，外接範圍寬高為 `abs(Δx)+1`、`abs(Δy)+1`。例如 `(10,20)→(13,24)` 的長度為 5px、寬高為 4×5px；同一像素的長度為 0px、寬高為 1×1px。顯示長度四捨五入至小數點後一位，整數可省略小數；幾何與計算不使用顯示後的捨入值。
- **編輯器尺寸標註**：尺規工具以拖曳建立線段，兩端有垂直界線、中央顯示長度，狀態列顯示長度與 Δx、Δy。支援移動、調整端點、顏色／線寬、再製、刪除、層序、復原／重做；長度標籤隨端點更新，與線段一起輸出至 PNG／剪貼簿。
- **覆蓋層量測**：按 R 切換量測模式，清楚顯示模式提示；拖曳顯示線段、長度、Δx、Δy、外接寬高，放開後保留直到下一次拖曳。再按 R 返回區域選取；切換模式捨棄進行中的預覽，不建立文件。量測限起始顯示器，Ctrl 放大鏡與 C 取色仍可用，Esc 或右鍵結束並恢復先前文件。

驗收：AT-14、Phase 11 煙霧驗證；同樣兩個像素在編輯器與覆蓋層須顯示相同長度。

**FR-42 截圖歷史**

v1.2 預設開啟本機磁碟歷史。每次完成的一般截圖與長截圖建立一個條目，保存原圖 PNG、縮圖與內部 JSON（時間、尺寸、全部標註、裁切、結構版本），位置固定於 `%LocalAppData%\ScreenshotApp\history\`。完整顯示器快照及未完成操作不寫入，開啟既有圖片也不新增。歷史不是故障日誌，也不是對外的 `.shot` 專案格式。

1. 截圖完成時背景寫入原圖；文件被取代、關閉、結束，以及每次成功複製或另存後，更新該條目的標註與裁切。先寫同資料夾暫存檔再取代；同一條目的寫入須按順序完成，避免較舊資料覆寫新資料。結束程式時有限等待進行中的寫入，逾時或失敗須提示且不得留下可被誤認為完整的半筆資料。歷史寫入不等於匯出，不解除 FR-23 的未匯出變更保護。
2. 系統匣與編輯器提供「截圖歷史」入口，同時只開一個歷史視窗，按新到舊顯示縮圖、時間、尺寸。可重新開啟繼續編輯、複製合成結果、刪除單筆與確認後清除全部。重新開啟須保護目前文件；還原原圖、標註與裁切，復原／重做堆疊為空，還原的初始狀態視為未修改，不另建重複條目。
3. 保留筆數預設 50、可設 1～500；超過時依建立時間淘汰最舊條目，修改舊條目不使其變成新截圖。關閉歷史後停止新增與更新，既有條目保留至刪除或清除；重新啟用只對之後完成的截圖新增，不補存關閉期間的內容。刪除、清除或淘汰已開啟文件的條目後，後續自動更新不得使其復活。
4. 第一次建立歷史資料夾時，以系統匣通知告知已開啟本機歷史及關閉／清除方式；升級後缺少此設定也依預設開啟。資料未加密，包含可還原的原圖與標註，文件與設定須明確告知。
5. 讀寫失敗不得阻擋截圖或編輯；回報原因並避免重複通知洗版。原圖可讀但 JSON 損毀、含未知標註或未來版本時，只還原原圖並提示，保留原條目不自動覆寫；原圖損毀的條目不可開啟，不完整的暫存寫入於下次啟動清理。清除與寫入須協調，成功清除後不能被先前排程的寫入重建。

驗收：AT-08、AT-15、MT-15；自動化測試只能使用測試暫存目錄，煙霧腳本不得污染或刪除使用者既有歷史。

**FR-43 長截圖**

從系統匣「長截圖」或選用快捷鍵進入；沿用覆蓋層選取單一顯示器內的範圍。有效選取後先關閉覆蓋層，再進入獨立捲動工作階段，不立即開啟編輯器。範圍外顯示不搶前景、滑鼠穿透的框線，控制面板提供目前高度、預覽、自動捲動／停止、完成與取消；框線和面板不得出現在取樣內容中，若無法避開則擷取前隱藏並等待桌面更新。

- **手動為預設**：使用者可在範圍內直接捲動底下的程式。程式等影格穩定後擷取、對齊並向下附加新內容；只支援垂直向下，往回捲動不附加。固定標頭／頁尾不得重複加入；無變化不附加，找不到可靠的重疊或遇到重複內容而無法判定時不猜測，保留已拼接部分並提示。
- **自動捲動**：按下後對選定範圍的程式送出向下捲動，等待穩定再擷取，不依賴固定捲動量。偵測使用者移動滑鼠、按鍵或按「停止」即停止自動捲動並回到手動，保留已拼接內容。連續多次穩定影格無變化時視為到底並自動完成；滾輪注入方式、穩定判定與次數須於 Phase 13 實測後寫入 ADR 與測試。自身送出的輸入不得誤判為使用者介入，不使用低階 Hook。
- **上限與結束**：高度上限 32,768px，總像素上限 100,000,000；選定單一影格已超過任一上限時拒絕開始並提示。只附加上限內的完整新列，到達上限時停止擷取、保留有效結果並提示。按「完成」後開啟編輯器並依歷史設定新增條目；未捲動就完成等同單一影格。取消不建立文件或歷史，關閉框線與面板並恢復先前狀態；擷取失敗或顯示設定改變時安全取消並提示。

長截圖整段工作階段都必須阻擋截圖重入、開啟其他圖片與歷史，避免替換正在處理的文件。動態內容、平滑捲動、浮動元素及無法接收注入的程式須記錄實測限制。驗收：AT-16、MT-13、Phase 13 煙霧驗證。

## 5. 核心工作流程與狀態管理

應用程式採以下狀態：

**Resident → Capturing → Selecting → Editing → Resident**

- `Resident`：常駐系統匣，等待快捷鍵或選單操作。
- `Capturing`：準備桌面快照、顯示器資訊與選取環境。
- `Selecting`：一般截圖顯示覆蓋層，供區域選取、放大、取色或量測；長截圖選好範圍後仍維持此忙碌狀態，直到捲動工作階段完成或取消。
- `Editing`：載入圖片，執行標註、裁切與匯出。

行為規則：

1. 截圖期間再次收到快捷鍵，應忽略重複事件，不可重入截圖或選取流程。
2. 使用者取消選取時，返回先前狀態。若原本已有編輯文件，須恢復原文件及視窗。
3. 新截圖可能覆蓋未匯出內容時，在開始新截圖前先處理確認。
4. 複製或另存 PNG 後，留在編輯狀態，讓使用者繼續工作。
5. 關閉編輯視窗只返回系統匣常駐，不退出程式。
6. 只有選擇系統匣「結束」，才真正終止應用程式。
7. Capturing／Selecting 期間忽略一般截圖、長截圖、開啟圖片、顯示歷史／設定與第二個執行個體的喚醒要求。長截圖的捲動工作階段亦同，不因覆蓋層已關閉而解除重入保護。
8. 取色成功或失敗皆不替換文件；量測、取色與取消不寫入歷史。長截圖僅在完成時開啟新文件；所有結束路徑都關閉自家擷取視窗並恢復之前隱藏的視窗。
9. 從歷史開啟與開啟圖片相同，必須保護未匯出變更；等待背景解碼或匯出期間的新修改也不得被替換。歷史自動寫入不代替使用者的複製／另存。

## 6. 程式架構與資料模型

### 6.1 建議目錄結構

`ScreenshotApp` 是唯一的 WPF 應用程式專案。

- `Platform/`：HotkeyService、TrayService、CaptureService、MonitorService、StartupService 與 Win32 Interop。
- `Capture/`：SelectionOverlay、SelectionController、螢幕快照管理。
- `Editor/`：EditorWindow、ViewModel、工具控制器、Canvas／Adorner、文件與標註物件。
- `Editor/Commands/`：操作命令及 Undo／Redo。
- `Export/`：ImageRenderer、ClipboardService、PngFileService。
- `Settings/`：AppSettings、JSON 持久化及設定畫面。
- `Resources/`：圖示、樣式與使用者介面文字。
- `ScreenshotApp.Tests/`：座標、裁切、編輯歷史、圖片合成及設定測試。
- `docs/`：架構、操作手冊、驗收與已知限制。

### 6.2 圖片文件模型

**ImageDocument**

必須持有原始 Bitmap、原始整數像素寬高、`CropRectPx`、按層序排列的 `Annotations`、匯出版本與編輯狀態。原始 Bitmap 在目前編輯工作階段中不得被標註操作覆寫。

**PixelRect**

具有 `X, Y, Width, Height`。使用整數實體像素與左上包含、右下不包含的半開區間表示，且必須位於原始圖片邊界內。

**Annotation**

包含唯一識別、種類、圖形座標或端點、Z-order 與樣式。文字物件增加 Text、FontFamily、FontSizePx；步驟編號增加 Number。

馬賽克與模糊增加整數矩形與強度，只從原圖產生效果點陣圖；尺寸標註持有兩端點與樣式，長度由端點計算。歷史保存所有種類的標註與裁切快照，不保存命令堆疊。內部格式帶結構版本，未知版本不得當作已支援的格式覆寫。

### 6.3 座標處理

所有物件與裁切範圍，永遠以**原始圖片像素原點**為基準。裁切時不重新寫入全部標註物件座標。

座標轉換必須集中管理：

`DesktopPhysicalPx ↔ MonitorLocalPx ↔ ImagePx ↔ ViewDIP`

不得在不同工具內自行散布互不一致的 DPI 換算。

### 6.4 輸出合成器

`ImageRenderer` 必須先依原始圖片座標合成整張原圖及標註，再取出 `CropRect` 的像素，產出指定大小的 Bitmap；不得先平移至裁切原點再繪製，以免平滑像素隨位置改變。效果標註也使用這條共用繪製路徑。

可使用 WPF `DrawingVisual` 與 `RenderTargetBitmap`，但必須明確控制輸出 DPI 與轉換比例。

WPF 圖形物件的執行緒親和性必須正確處理。耗時圖片編碼與檔案 I/O 不應長時間阻塞 UI Thread；跨執行緒傳遞圖片物件時，需遵守 WPF Dispatcher／STA 與 Freezable 的限制。

### 6.5 Windows 平台整合

- 啟動採 `ShutdownMode.OnExplicitShutdown`，保留可接收 `WM_HOTKEY` 的隱藏視窗或訊息接收器。
- 透過 Windows 顯示器 API 取得實體像素邊界，為各顯示器建立正確 DPI 的選取遮罩。
- GDI `BitBlt` 配合記憶體 Bitmap 實作擷取；HDC、HBITMAP 等非受控物件必須明確管理生命週期。
- Windows Forms `NotifyIcon` 僅用於系統匣，主要介面一律為 WPF。
- 設定與檔案操作使用目前使用者可寫路徑，不提高權限。

## 7. 非功能性規範

**NFR-01 離線與隱私**：無雲端、帳號、遙測、廣告、背景上傳或外部網路呼叫。除使用者另存與 FR-42 明確定義的本機歷史外，不記錄圖像與文字標註內容；故障日誌不得包含這些內容。

**NFR-02 安全性**：不提高權限、不搶用 Windows 保留的截圖快捷鍵、不使用低階鍵盤或滑鼠 Hook。未明確另存的圖像僅可依 FR-42 寫入本機歷史；關閉歷史後停止自動新增與更新。歷史的檔案操作限於專用根目錄，文件須揭露原圖未加密，以及馬賽克／模糊不會刪除文件或歷史中的原始資料。

**NFR-03 效能**：FHD、4K 截圖及編輯應具備日常可接受的互動流暢度。大型圖片處理與檔案編碼不得長時間阻塞 UI。優先量測實際操作延遲，不進行無意義的大量壓力測試。

**NFR-04 資源管理**：重複截圖、取消、編輯後不得持續累積 GDI Handle、Bitmap、視窗或事件訂閱。超大圖片應有輸入檢查及友善失敗處理。

**NFR-05 例外處理**：Win32 API、剪貼簿、檔案 I/O、圖片解析、顯示器變更失敗時，應可回復並以繁體中文提供明確提示。

**NFR-06 可維護性**：隔離 Windows API、圖片資料模型、編輯指令及輸出合成器；不得過度導入 DI Container、事件匯流排、外掛架構或不必要框架。

**NFR-07 相容性**：以 Windows 11 x64 為正式驗收平台，混合 DPI、多螢幕與微軟注音必須驗證。

**NFR-08 操作性**：主要功能應支援工具列及鍵盤操作，並具備焦點顯示及工具提示。

**NFR-09 故障紀錄**：如需本機故障日誌，僅保留必要錯誤與堆疊資訊，限制檔案大小及保留期間，不記錄圖像或使用者輸入文字。

## 8. 測試策略與驗收條件

### 8.1 自動化測試

**AT-01 座標映射**：驗證正負螢幕起點、混合 DPI、非主螢幕、縮放與平移；往返轉換誤差不超過 1px。

**AT-02 選取矩形**：驗證各方向拖曳、邊界夾取、零尺寸、半開區間及跨顯示器拖曳限制。

**AT-03 裁切**：驗證連續裁切、調整裁切框、撤銷、重做、極小裁切及還原完整圖片；輸出尺寸必須吻合。裁切後符合視窗的上限（整張圖片 100%、裁切範圍 400%）。

**AT-04 標註物件**：驗證新增、移動、調整大小、修改顏色、刪除、Z-order、重疊物件選取、再製、反轉箭頭方向、重新編號所有步驟與清除所有標註。右鍵選單依情境選擇選單與項目狀態。

**AT-05 Undo／Redo**：驗證所有操作可逆、一次拖曳只形成一筆、作用於多個標註的操作只形成一筆、新修改清除 Redo 及歷史上限。

**AT-06 文字**：驗證繁體中文、英文、Unicode、換行、重新編輯、空文字取消與最終匯出。

**AT-07 合成**：同一文件在不同畫布縮放下，輸出尺寸及圖片內容一致，裁切外標註不得出現。

**AT-08 設定**：驗證正常載入、快捷鍵變更、JSON 損壞復原、權限不足及無效路徑。

**AT-09 錯誤恢復**：模擬剪貼簿或檔案儲存失敗，不得失去正在編輯的內容。

**AT-10 圖片匯入**：驗證有效 PNG、JPEG、BMP 與格式錯誤、檔案損壞及無效尺寸。

**AT-11 放大鏡幾何**：驗證四角、邊緣翻轉、超出顯示器的中性色格、奇數取樣格的中心與游標像素相同、整數實體像素倍率；含負桌面座標與不同 DPI。Ctrl 從觸發截圖延續按住與重複 KeyDown 不顯示，重新按下才顯示，放開／捕捉遺失隱藏。

**AT-12 取色**：已知快照與原圖的 RGB 應得到相同的大寫 `#RRGGBB`，不受暗化、縮放或上層標註影響。覆蓋層取色的成功／剪貼簿失敗皆恢復舊文件、不新增文件或歷史；測試以委派替代真實剪貼簿。編輯器取色對選取標註產生一筆可復原變更，未選取時更新預設值，完成／取消回復原工具，畫布外點擊不取色。

**AT-13 效果標註**：以已知輸入及獨立算出的期望值驗證區塊平均、三次盒狀模糊、捨入、非完整區塊、均勻色區、1×1px、強度邊界及圖片邊界。確認只取樣原圖、不透明覆蓋下層標註、上層標註照常繪製、範圍外不變；PNG 與剪貼簿可視像素相同，不附帶原圖。延伸 AT-04／05／07 驗證建立、移動、大小、強度、再製、層序與復原，每次操作一筆命令，裁切交界與未裁切輸出的相同範圍一致。不要求每個輸出像素必須不同於原值。

**AT-14 尺規與量測**：驗證水平、垂直、斜向、反向與同一像素的中心距離、Δx／Δy、包含端點的寬高與顯示捨入；兩個入口使用同一定義。尺寸標註可調整、移動與復原，輸出不隨畫布縮放改變；覆蓋層 R 切換、放開保留、下一次拖曳取代、取消與捕捉遺失不建立文件。

**AT-15 截圖歷史**：只在暫存根目錄驗證全部標註種類、裁切與原圖的往返及還原輸出相同、復原堆疊為空、初始未修改。驗證預設值與 1～500 筆範圍、最舊淘汰、關閉後不寫入、重新啟用不補存、刪除／清除與待寫佇列不使條目復活、原子寫入、不完整條目清理、損毀／未知版本只讀原圖且不覆寫。寫入失敗或結束等待逾時不得阻擋截圖與編輯，不得取消未匯出變更保護或寫入使用者目錄。

**AT-16 長截圖拼接**：以合成的連續內容影格驗證不同向下位移、固定標頭／頁尾、無變化、往回捲動、重複區塊與對齊失敗，以及高度／總像素上限前後。對齊成功的結果逐像素等於預期連續內容；失敗不附加、不破壞前段。以流程替身驗證完成、取消、擷取失敗、顯示變更、自動捲動停止、上限、未捲動直接完成與重入保護；實際滾輪注入另以 MT-13 驗證。

### 8.2 Windows 實際操作驗收

**MT-01**：首次啟動只進系統匣；再次啟動不重複常駐；退出後重新啟動熱鍵可用。

**MT-02**：預設及自訂快捷鍵在桌面、瀏覽器及 PowerPoint 中可以啟動截圖；被占用時有明確提示。

**MT-03**：拖曳選取後自動開啟編輯器；取消不留下遮罩，且不影響先前文件。

**MT-04**：單螢幕 100%、125%、150%、200% 縮放下，選取與 PNG 尺寸正確。

**MT-05**：雙螢幕不同 DPI、負 X 座標、上下排列、非主螢幕截圖正確。

**MT-06**：微軟注音輸入繁體中文並重新編輯，不發生組字中斷、錯字或文字位移。

**MT-07**：文字、箭頭、方框與步驟編號在 25%、100%、400% Zoom 操作後，匯出結果一致。

**MT-08**：圖片貼入 PowerPoint 與 PNG 內容一致；Word／Teams 可接受圖片資料。

**MT-09**：磁碟不可寫、剪貼簿被占用、顯示器中途拔除等錯誤發生後，應能回復可操作狀態。

**MT-10**：執行至少 30 次截圖、取消、編輯、複製、儲存及關閉循環，檢查 GDI Handle 與記憶體是否存在持續成長趨勢。

**MT-11**：在沒有安裝 .NET Runtime 的乾淨 Windows 11 x64 環境，發佈版本仍可正常截圖及輸出。

**MT-12 放大鏡與取色／量測**：在 100%、125%、175%、200% 縮放及混合 DPI 多螢幕，用已知圖樣驗證 Ctrl 需重新按下、放開隱藏、跨螢幕與四角位置、中心格與 RGB、使用放大鏡選出的結果逐像素正確。C 複製正確色碼且保留舊文件；R 量測已知端點符合 FR-41、不建立截圖，返回區域選取可正常截圖。

**MT-13 長截圖**：分別在瀏覽器長網頁、Word、程式碼編輯器及已知可捲動圖樣中操作手動與自動捲動；圖樣結果逐像素正確，固定標頭／頁尾不重複。驗證使用者介入停止自動、到底完成、取消、達到上限、重入與顯示變更後無殘留視窗；記錄程式版本、縮放與平滑捲動條件，無法支援者明列限制。

**MT-14 效果與尺寸標註輸出**：對已知圖樣及測試用文字分別加上馬賽克、模糊與尺寸標註，調整強度／端點、復原並匯出；貼入 PowerPoint 後與 PNG 的可視像素一致。記錄圖樣、強度與縮放下文字是否仍可辨識，確認沒有透明漏出原圖；可辨識就提高強度或標示限制，不把視覺檢查宣稱為不可還原的保證。編輯器取色取到原圖色，後續矩形套用該色。

**MT-15 截圖歷史**：在隔離測試資料中驗證第一次建立的通知、一般／長截圖新增、關閉或重新啟動後還原標註與裁切、長時間常駐的磁碟／記憶體占用，以及預設 50 筆與調整後的淘汰。驗證關閉歷史後停止寫入、清除確認、寫入失敗仍可編輯；逐項記錄使用的版本、圖像尺寸、操作次數與未驗證情境。煙霧腳本關閉歷史或使用可識別的測試條目，結束只清理自己建立的資料並還原設定。

## 12. 技術風險與既有限制

**風險 1：混合 DPI 座標偏移。** 必須先完成座標模型及多螢幕驗證，不得等編輯器完成後才補救。

**風險 2：剪貼簿與 PNG 內容不一致。** 必須共用唯一圖片合成器，並以 PowerPoint 實際貼上驗證。

**風險 3：WPF 文字輸入法與匯出差異。** 使用標準 WPF TextBox 完成文字輸入，再更新標註模型，實測繁體中文 IME。

**風險 4：GDI 非受控資源洩漏。** HDC、HBITMAP 等資源必須具有明確所有權及例外安全清理機制。

**風險 5：受保護畫面與 UAC 安全桌面。** 不承諾可擷取，列入文件的已知限制。

**風險 6：無可攜的專案格式。** PNG 是最終成品，無法還原獨立標註；v1.2 只對仍保留的本機歷史條目提供繼續編輯，不保存復原堆疊。歷史關閉期間的新截圖與修改、已清除／淘汰的條目或開啟的既有圖片，關閉文件後無法由歷史恢復；關閉歷史前已保存且未刪除的條目仍可開啟。

**風險 7：超大圖片。** 必須檢查可處理尺寸與預估資源，遇到超出合理記憶體範圍的圖片應明確拒絕或友善失敗，避免程式無回應。

**風險 8：預設磁碟歷史。** 原圖可能包含已裁切掉或已用效果遮蔽的內容，未加密且會占用磁碟；須提供初次通知、關閉、清除與保留上限。歷史不是安全刪除機制，不宣稱能移除作業系統或備份中的副本。

**風險 9：效果仍可辨識。** 模糊與馬賽克的可辨識度受內容及強度影響；只保證依演算法合成，不保證資訊無法推測。效果標註不刪除文件或歷史中的原圖。

**風險 10：長截圖對齊與輸入。** 動畫、平滑捲動、固定元素、重複內容與輸入注入限制可能導致無法可靠對齊；不確定時不附加，保留已完成內容並提示，依實測記錄支援範圍。
