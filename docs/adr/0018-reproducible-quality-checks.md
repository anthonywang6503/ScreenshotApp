# ADR-0018：固定工具鏈與本機／Windows CI 共用的品質檢查

- **狀態**：Accepted
- **日期**：2026-10-29

## 背景

產品與測試的 Release 建置原本為零警告，完整測試也通過，但沒有 CI 或 SDK 選擇設定；手動執行建置與測試不會把警告視為失敗，亦未確認是否真的有測試執行。測試套件的間接版本沒有鎖定檔。

## 決策

1. global.json 固定目前已實測的 SDK 10.0.403，停用版本前移與預覽版。兩個專案提交 NuGet lock file，品質檢查以 locked mode 還原；不升級任何產品或測試套件。
2. `tools/Invoke-Quality.ps1` 為本機與 CI 共用的完整整合檢查：鎖定還原、Release 建置、所有測試。還原與建置的警告視為錯誤；保留原本有理由的 WFO0003 抑制。
3. 每次產生獨立 TRX，要求至少一個測試且全部通過；任何原生命令失敗、空報告或跳過測試都不能回報成功。
4. CI 在 Windows Server 2025 runner 執行同一入口，權限只讀、Actions 固定 commit，保存測試報告，不加入發佈或部署。
5. 以獨立原始碼副本驗證警告、失敗測試、跳過測試與套件版本偏離鎖定檔都能使入口失敗。一般局部修改仍維持既有的最小必要測試原則。

## 影響與驗證邊界

- 開發機須安裝指定 SDK；更新工具鏈或套件時要明確更新對應檔案並重新驗證。
- 不拆分測試專案、不引入框架、不更動產品行為或使用者資料。
- CI 設定經 actionlint 驗證，入口與負向路徑已在本機測試；遠端 runner 的實際執行仍待後續授權推送後確認。
- 操作與診斷見 [品質檢查說明](../QUALITY.md)。
