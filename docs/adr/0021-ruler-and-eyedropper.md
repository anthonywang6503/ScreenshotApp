# ADR-0021：尺規、覆蓋層量測與編輯器取色

- **狀態**：Accepted
- **日期**：2026-11-02

## 決策

1. 兩個入口共用 `PixelMeasurement`：端點為整數像素，Δ 為終點減起點，長度為像素中心的歐氏距離，外接寬高為絕對差加一。先以 double 計算差值避免整數平方溢位，顯示以 AwayFromZero 四捨五入至一位，整數省略小數。例如 (10,20)→(13,24) 為 5px、Δ=(3,4)、4×5px；反向僅改變 Δ 符號。
2. `RulerAnnotation` 繼承線段標註，沿用端點、移動、線寬、顏色與命令。界線半長為 max(6, 3×線寬)，字級為 max(12, 4×線寬)；白底黑字標籤放在線段中央，限制在原圖內。模型保留原圖邊界供顯示、命中與輸出使用同一標籤位置；圖片比標籤小時等比例縮小。裁切仍是完整合成後取出範圍，不重新移動標籤。
3. 尺規的界線與標籤皆可命中，兩端可調整；拖曳建立未離開起點不建立標註，既有端點可以重合並顯示 0px。狀態列優先顯示正在拖曳或選取的尺規數值。
4. 覆蓋層 R 僅接受無修飾鍵且非重複按下。切換時清除全部選取／量測預覽並釋放捕捉；量測限制在起始顯示器，放開後保留，下一次按下（含其他顯示器）清除舊線。捕捉遺失丟棄進行中量測，正常放開保留結果；不完成截圖。Esc、右鍵與顯示設定變更沿用既有取消流程。Ctrl 放大鏡與 C 取色皆保留。
5. 編輯器取色是暫時工具，保存原本工具與文字輸入，不提交輸入中的文字。點擊原圖內才取樣，先驗證範圍再換成像素，禁止夾取圖片外點。取樣轉為 Bgra32 讀 RGB（含索引色、灰階及預乘透明來源），不讀取合成標註。透過 `SetColor` 套用：選取標註一筆替換命令、新文字／無選取更新既有預設設定、效果忽略顏色。成功或 Esc 返回原工具，成功以狀態列顯示色碼。
6. 工具使用圖示、文字、工具提示及 Alt 存取鍵（Q 尺規、D 取色）；不攔截文字輸入中的一般字母。新增文字集中於 Strings.resx。

## 權衡與驗證

- 不新增尺規字型或單位設定，固定實體像素；標籤會遮住線段中央的小範圍。
- 尺規為 [文件模型](0010-document-model-and-commands.md) 的線段擴充，繪製沿用 [共用繪製決策](0011-shared-annotation-painter.md)。
- 自動化涵蓋量測、命中、命令、輸出／裁切、取色與覆蓋層狀態；真實鍵鼠與混合 DPI 仍依 [驗收紀錄](../ACCEPTANCE.md) 區分。
