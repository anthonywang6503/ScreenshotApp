# ADR-0022：本機截圖歷史

- **狀態**：Accepted
- **日期**：2026-11-02

## 決策

依使用者明確選擇與 [FR-42](../ScreenshotApp.Spec.md)，歷史預設開啟，取代原本不自動保存截圖的限制。保存於 `%LocalAppData%\ScreenshotApp\history\<UTC時間戳記_GUID>\`，包含 `original.png`、`thumb.png` 與最後提交的 `document.json`。JSON 結構版本為 1，明確列舉九種標註、識別碼、顏色、幾何及樣式；尺規的原圖邊界由解碼後尺寸重建。

原圖於截圖完成時保存；文件取代、關閉、結束與成功匯出後更新標註及裁切。UI 執行緒取得不可變快照，背景佇列依呼叫順序編碼與存取磁碟。原圖與縮圖建立完成後才原子提交 JSON；更新只取代 JSON，因此縮圖代表原始截圖。讀取、刪除、清除與淘汰也經過同一佇列。每個檔案先寫同目錄暫存檔再取代；不完整條目下次啟動清理。

關閉歷史使舊寫入世代失效，解除開啟文件的歷史關聯；重新啟用不補存關閉期間內容。已刪除或淘汰條目的更新只在完整條目仍存在時寫入，絕不重新建立。保留上限 1～500，預設 50，以建立時間而非修改時間排序。清除保留根目錄，避免重複初次通知。

JSON 損毀、未知標註或版本及無效數值，整份標註與裁切不採用；只開原圖並提示，該次還原不建立可寫關聯，避免自動覆寫原始證據。原圖無法解碼時不開啟。所有路徑由內部識別碼與固定檔名構成，拒絕路徑跳脫及重新解析點，不遞迴跟隨外部目錄。

首次建立根目錄後通知使用者預設保存、未加密與關閉／清除方式。讀寫失敗回傳原因；每次程式執行最多一次背景失敗通知，日誌不記錄 JSON、圖像或文字內容。正常結束最多等待 3 秒，逾時提示後結束；未提交 JSON 的資料不視為完整。

歷史不修改匯出版本。歷史開啟沿用未匯出確認與解碼期間新修改保護；初始復原堆疊為空。測試使用注入的暫存根目錄，既有煙霧腳本先關閉歷史；專用煙霧在隔離資料範圍執行。

## 取捨

原圖縮圖讓儲存不需要背景 WPF 合成與額外快取；歷史複製及重新編輯才依完整標註合成。磁碟資料不加密，原圖包含裁切及遮蔽之前的內容。歷史不是對外專案格式，也不是匯出或安全刪除機制。
