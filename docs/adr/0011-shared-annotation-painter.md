# ADR-0011：共用 AnnotationPainter——顯示與匯出同一繪製碼

- **狀態**：Accepted
- **日期**：2026-10-18

## 背景

規格要求 PNG 與剪貼簿輸出統一透過同一個 `ImageRenderer`，輸出寬高嚴格等於 `CropRect`，圖形座標、字級與線寬依圖片像素呈現，畫布顯示縮放不得影響輸出。若編輯畫布以 WPF Shape 或 Adorner 顯示標註、匯出時再另寫一套繪製，兩邊的線寬、箭頭頭部、文字斷行遲早會不同，使用者看到的與複製出去的不一致。

## 決策

1. **`AnnotationPainter`** 是唯一的標註繪製碼：以 `DrawingContext` 在**圖片像素座標**繪製單一標註。編輯畫布的標註層位於縮放容器之內（區域單位即圖片像素），匯出時在 96 DPI 的點陣圖上以同一份程式繪製。
2. **與 DPI 無關**：`FormattedText` 的 pixelsPerDip 固定為 1.0；文字只依明確的換行斷行，不自動換行；畫布與匯出的文字都使用灰階平滑，不使用 ClearType。螢幕上的 DPI 與縮放由 WPF 的轉換處理，繪製碼不知道縮放比例。
3. **繪製規則**（以整數線寬為準）：
   - 矩形：筆劃畫在範圍內側（以線寬一半內縮），水平與垂直邊恰好落在像素格線上，不會模糊；範圍比線寬還小時整塊填滿。
   - 橢圓：同樣以線寬一半內縮。
   - 直線、箭頭：通過端點像素的中心，圓形線帽；箭頭頭部為實心三角形，大小隨線寬增加，線段很短時等比例縮小，線身終止於頭部內，不會從尖端露出。
   - 文字：`FormattedText` 繪於起點，字型、字級為圖片像素。
   - 步驟編號：實心圓，編號以粗體置中（以文字外框幾何計算中心），多位數時縮小字級以放入圓內，數字顏色依底色亮度選黑或白。
4. **`ImageRenderer`**：建立 `CropRect` 寬高、96 DPI、`Pbgra32` 的 `RenderTargetBitmap`，平移 `(-CropRect.X, -CropRect.Y)` 後以原始像素尺寸繪製底圖（不使用檔案內的 DPI）、再以 `AnnotationPainter` 依層序繪製全部標註，最後凍結。底圖使用最近鄰取樣，整數平移下輸出像素與原圖完全相同。

## 考慮過的替代方案

- **畫布以 WPF Shape／TextBlock 顯示，匯出另寫繪製**：開發快，但兩套程式的細節（線帽、內縮、箭頭、文字度量）必然分歧。
- **以 GDI+（System.Drawing）匯出**：光柵化引擎與螢幕上的 WPF 不同，文字與反鋸齒結果不一致。
- **筆劃置中於矩形邊界**：3px 線寬會跨越像素格線，水平與垂直邊出現半透明的邊緣。

## 影響

- 畫面、PNG 與剪貼簿的圖形差異只剩光柵化本身；100% 縮放時畫布上的標註與輸出逐像素接近。
- 渲染測試可直接以圖片像素驗證：輸出尺寸、裁切外不出現標註、底圖像素不變、不同縮放下結果相同。
- 新增標註種類時只需擴充模型與繪製碼各一處。
