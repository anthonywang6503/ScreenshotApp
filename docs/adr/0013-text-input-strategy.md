# ADR-0013：文字輸入策略——WPF TextBox 覆蓋 + IME

- **狀態**：Accepted
- **日期**：2026-10-18

## 背景

文字標註需支援微軟注音、台灣繁體中文、英文、Unicode 與換行；完成後可雙擊重新編輯，並修改字級、顏色與基本字型；建立或完成修改各為一筆 Undo 操作。正在編輯文字時，`Ctrl+C` 等按鍵應優先遵循文字編輯行為，避免破壞輸入法組字。規格指出 WPF 文字輸入法與匯出結果可能不一致，建議以標準 WPF TextBox 完成輸入，再更新標註模型，並實測繁體中文輸入法。

## 決策

1. **在畫布上以 WPF `TextBox` 原地輸入**：TextBox 放在縮放容器內的文字輸入層，區域單位即圖片像素，因此字級等於標註的像素字級並隨縮放一起縮放。輸入法、選取、複製貼上、方向鍵與輸入框內的 Undo 全由 TextBox 處理。
2. **與繪製結果對齊**：TextBox 不換行（只接受明確換行）、透明背景、無框線，使用與 `AnnotationPainter` 相同的字型、字級、顏色與灰階文字平滑。版面完成後以第一個字元的位置量測 TextBox 內部的文字偏移，把 TextBox 放在「標註起點減去偏移」處，完成輸入後由繪製碼畫出的文字不會位移。
3. **結束編輯**：`Ctrl+Enter`、在輸入框外按下滑鼠、切換工具、複製、儲存或取代文件時提交；`Esc` 取消。提交規則：新文字非空白 → 新增；既有文字有變更 → 替換；既有文字清空 → 刪除；新文字為空 → 不建立。每次提交至多一筆命令。
4. **重新編輯**：選取工具下雙擊文字標註，或文字工具下點擊既有文字標註。編輯期間標註層隱藏原本的標註，由 TextBox 顯示同樣的內容。
5. **樣式**：編輯中變更顏色、字型或字級，直接套用到正在編輯的文字（新文字同時成為之後的預設值），焦點隨即回到 TextBox。
6. **按鍵路由**：編輯器快捷鍵以視窗的 `InputBindings` 註冊（事件冒泡階段），TextBox 先處理按鍵與輸入法組字；文字編輯期間這些快捷鍵（`Ctrl+C`、`Ctrl+Z`、`Ctrl+Y`、`Delete`、`Esc`）一律不執行編輯器動作，即使 TextBox 沒有處理（例如沒有選取文字時按 `Ctrl+C`）也不會改為複製整張圖片。`Ctrl+Enter` 由 TextBox 自己的按鍵處理先攔截。

## 考慮過的替代方案

- **自行處理鍵盤與輸入法組字**：需直接處理 TSF／IMM 的組字與候選字視窗，錯誤風險高，正是規格點名的風險。
- **另開對話框輸入文字**：實作簡單，但看不到文字在圖片上的位置與大小，重新編輯也不直覺。
- **`RichTextBox`**：支援混合樣式，超出需求；與單一樣式的繪製碼對齊更困難。
- **在視窗的 `PreviewKeyDown` 攔截快捷鍵**：會在 TextBox 之前收到按鍵，破壞輸入法與文字框自身的複製、復原。

## 影響

- 中英文、Unicode 與換行的模型與輸出可自動化測試；微軟注音的組字、選字與重新編輯需由使用者實機驗證。
- 輸入中與完成後的對齊需實機截圖確認；若量測到位移，調整 TextBox 的偏移量測。
- 文字自動換行不在 v1.0 範圍；長文字以明確換行分行。
