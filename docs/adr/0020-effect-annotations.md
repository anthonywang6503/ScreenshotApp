# ADR-0020：原圖取樣的馬賽克與模糊標註

- **狀態**：Accepted
- **日期**：2026-11-01

## 決策

1. `EffectAnnotation` 是不可變標註，保存整數 `Rect` 與 `Strength`，整塊命中、八個控制點，沿用 `BoxHandles` 與新增／替換命令。共用基底的 Color 保留相容性，但效果不使用它，介面與樣式命令均忽略效果顏色。零位移不建立；調整後至少 1×1px。
2. 馬賽克區塊邊長為 2～64px，預設 12px；模糊半徑為 1～32px，預設 6px。各工具的預設強度只保存在工作階段；選取效果時改強度只替換該標註，不改設定檔。屬性列選擇一個整數即一筆命令，同值不新增命令。
3. 馬賽克以標註矩形左上角為區塊原點，即使矩形超出圖片，仍保留原區塊格線；每塊只平均與原圖相交的像素。RGB 每通道以 `(sum + count / 2) / count` 整數四捨五入。
4. 模糊在矩形與原圖相交範圍內執行三輪「水平、垂直」盒狀模糊，每個方向使用相同半徑，邊界縮短取樣範圍並重新計數，每一方向後依上述規則捨入為位元組。滑動總和讓成本與像素數成正比，不隨半徑倍增。均勻色區與 1×1 保持原色。
5. 原圖以未預乘的 RGB 取樣，忽略 alpha；輸出為凍結、96 DPI 的 `Bgr32`，依整數矩形覆蓋，完全不透明。取樣不包含下層標註；上層標註仍可覆蓋效果。先合成整張圖片，再取出裁切範圍。
6. `AnnotationPainter.Paint` 接受原圖，畫布與匯出傳入同一個 `ImageDocument.Source`。原圖已凍結且不可變，快取以原圖物件弱參照分組，鍵為完整矩形、效果種類及強度，忽略 Id／Color。每張原圖最多 8 筆、64 MiB 的 LRU 結果；超過容量的單筆直接計算不保存。移動、縮放或強度變更產生新鍵，舊鍵依容量淘汰；文件釋放後整組可回收。快取僅於 UI 執行緒操作，不存入命令歷史。
7. 不使用 WPF BlurEffect：它會取樣合成畫面且與匯出像素規則難以一致。也不新增另一套匯出繪製碼。

## 驗證與限制

- 以獨立逐像素參考演算法檢查平均、捨入、邊界、強度與三輪模糊；驗證原圖不變、不透明覆蓋、層序、裁切、PNG／DIB 與復原。
- 拖曳預覽同步重算；4K 計算時間須附實際建置與量測條件，不能以單元測試宣稱實機流暢。
- 模糊可能仍可辨識或部分還原；降低可辨識度時優先使用馬賽克並檢查匯出。兩者均不保證保密，原圖仍存在編輯文件與未來啟用的磁碟歷史；匯出僅攜帶合成像素，不攜帶原圖、標註或復原資料。
